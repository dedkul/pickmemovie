Logo hover: plain SVG version

Hover the logo, here or in the header above, or Tab to it. It plays once per hover. Compare with the current version at localhost:3001.

  • Same shapes and timing as the Remotion version: the lens opens, the mark tilts back and settles, the name flashes the accent colour, 1.48 s in all.
  • No packages. The motion is SVG <animate>, built into every browser.
  • Mouse hover and keyboard focus start it. Touch doesn't, matching the current version, and reduced motion skips it.
